# GitHub media provenance

These assets support the repository landing page and social preview. Product screenshots are separated from illustrative artwork so visual claims stay auditable.

| File | Classification | Notes |
| --- | --- | --- |
| `blockwright-hero.png` | Original generated illustration | Blockwright marketing art created with OpenAI image generation. It is not a product screenshot or generated Minecraft build. |
| `social-preview.jpg` | Derived illustration | 1280×640, quality-optimized derivative of `blockwright-hero.png` for GitHub's social preview. |
| `workbench-v050.png` | Product screenshot | Live local Blockwright 0.5.0 capture of the deterministic `readme-050` example, using procedural fallback materials and no external texture archive. |
| `reviewer-audit.png` | Product screenshot | Live local Blockwright 0.5.0 reviewer capture showing an exact audit coordinate, block state, generation phase, and review controls. |
| `windows-control-center.png` | Product screenshot | Live native Windows Control Center capture. The plugin-root label was generalized before capture; server/readiness and diagnostic state came from the running local app. |

Blockwright does not bundle Mojang texture artwork. Any user-selected resource-pack ZIP or client JAR stays in that user's browser.
